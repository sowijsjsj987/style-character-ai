# 모바일 그림체 캐릭터 AI

이 폴더는 휴대폰에서 사용할 수 있는 웹 화면(frontend)과 이미지 생성 서버(backend)입니다.

중요:
- index.html만 휴대폰에서 열면 화면은 나오지만 AI 생성은 되지 않습니다.
- 실제 생성 서버에 API 키를 안전하게 보관해야 합니다.
- API 키를 index.html에 넣으면 안 됩니다.

가장 쉬운 사용 방식:
1. GitHub 등에 이 파일들을 올립니다.
2. Python 서버를 실행할 수 있는 호스팅에 server.py와 requirements.txt를 배포합니다.
3. 호스팅 서비스의 비밀 환경변수에 OPENAI_API_KEY를 넣습니다.
4. index.html의 YOUR_SERVER_URL을 배포된 서버 주소로 바꿉니다.
5. index.html을 웹사이트로 배포하면 휴대폰 크롬에서 사용할 수 있습니다.

프로그램 기능:
- 캐릭터 이미지 업로드
- 그림체 참고 이미지 여러 장 업로드
- 포즈/배경 등 추가 요청
- 캐릭터 특징 보존 정도 선택
- 생성 결과를 휴대폰 화면에 표시
